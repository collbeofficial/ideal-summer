픽셀 스토리 게임 — HTML/CSS/JavaScript

실행 방법
1. ZIP 파일의 압축을 풉니다.
2. 폴더 안의 index.html을 Chrome, Safari, Edge 등으로 엽니다.

조작
- 이동: 키보드 방향키/WASD 또는 화면 우측 방향키
- 선택·대화·조사: 키보드 A 또는 화면 A 버튼
- 주머니: 키보드 B 또는 화면 B 버튼
- 대화 넘기기: 스페이스바, 대화창 클릭 또는 화면 터치
- 코끼리 안기: 코끼리 가까이에서 A와 B를 동시에 누르기

모바일
- 화면 방향키와 A/B 버튼을 터치해서 플레이할 수 있습니다.
- 두 손가락으로 A/B 버튼을 동시에 누르면 포옹 입력이 작동합니다.
