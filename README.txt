놓아두는 사랑 — HTML/CSS/JavaScript 픽셀 게임

실행 방법
1. ZIP 압축을 풉니다.
2. index.html을 브라우저에서 엽니다.
3. GitHub Pages에서는 폴더 안의 모든 파일과 assets 폴더를 함께 업로드합니다.

조작
- 이동: 방향키 / 화면 방향키
- 선택·대화: A / 화면 A 버튼
- 주머니: B / 화면 B 버튼
- 대화 넘기기: 스페이스바 / 대화창 터치

모바일 세로 화면
- 게임 화면 아래 검은 여백에 조작 버튼이 배치됩니다.
- 주머니는 손가락으로 위아래 스크롤할 수 있습니다.
